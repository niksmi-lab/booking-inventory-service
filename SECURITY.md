# Security Policy

## Reporting a vulnerability

Please do not disclose vulnerabilities in public issues.

Report security concerns to `nikishasmirnoff@gmail.com` with:

- the affected endpoint or component;
- reproduction steps;
- expected impact;
- any suggested mitigation.

Do not include real credentials, customer data or production database dumps. You should receive an acknowledgement within seven days.

## Supported versions

Security fixes are applied to the latest commit on the `main` branch.
